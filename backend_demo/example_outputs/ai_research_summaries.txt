# Research Summaries and Code Structures

## Paper 1: GenAI Content Detection Task 1: English and Multilingual Machine-Generated Text Detection: AI vs. Human
- **ArXiv ID:** 2501.11012v2
- **GitHub Repository:** https://github.com/mbzuai-nlp/COLING-2025-Workshop-on-MGT-Detection-Task1
- **Focus:** Binary machine-generated text (MGT) detection.
- **Key Details:**
    - Part of GenAI workshop at COLING 2025.
    - Two subtasks: Monolingual (English) and Multilingual.
    - Extensive analysis of submissions from 36 teams.

## Paper 2: EVOR: Evolving Retrieval for Code Generation
- **ArXiv ID:** 2402.12317v2
- **Project/Code Website:** https://arks-codegen.github.io
- **Focus:** Retrieval-Augmented Code Generation (RACG).
- **Key Details:**
    - EVOR pipeline: Synchronous evolution of queries and diverse knowledge bases.
    - Datasets: EVOR-BENCH (updated libraries, long-tail languages).
    - Results: 2-4x execution accuracy over existing methods (e.g., Reflexion).
